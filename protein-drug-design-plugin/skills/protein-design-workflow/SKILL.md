# 蛋白药物设计工作流编排 (Workflow Orchestrator)

本技能是路由层：把用户需求映射到本插件的三个执行技能，管理阶段间的数据契约与算力排期。配置声明见插件根目录 [workflow.yaml](../../workflow.yaml)。

## 1. 主流水线（五阶段数据流）

```text
[1] family-identification   seq-struct-analysis      输入: FASTA
        │ 输出: 家族归属 + 同源簇 + 结构锚点
        v
[2] structure-acquisition   structure-prediction-analysis
        │ 输出: model.cif + 置信度 (Mol-1 100-seed 批量 / 单结构; 2026-11-05 起 AF3→Mol-1)
        v
[3] structure-analysis      structure-prediction-analysis
        │ 输出: 四象限判定 + 口袋/epitope 几何
        v
[4] md-validation           md-simulation-workflow
        │ 输入: 阶段2/3 结构 + 可选配体 + 质子化态
        │ 输出: prmtop(三道守卫过) + 轨迹 + 稳定性/收敛判定
        v
[5] binding-energy          md-simulation-workflow
          输出: ΔG_bind ± 块平均SEM + 残基分解 (+可选 CpHMD/QM/MM 深化)
```

**数据契约**：每阶段的 inputs/outputs 在 workflow.yaml `stages` 中声明；上游产物即下游输入，格式以各技能 SKILL.md 的"产出清单"为准。

## 2. 任务路由规则

| 用户意图特征 | 路由 |
|---|---|
| 只给序列，问"这是什么/像谁" | 阶段 1 单跑 |
| 有结构/序列，要 AF3 预测或批量筛选 binder | 阶段 2-3 |
| 已有复合物结构，要动力学稳定性/结合模式验证 | 阶段 4（可跳过 2-3） |
| 要 ΔG 定量、排名、残基贡献 | 阶段 4→5 |
| 全新蛋白从零到机制 | 1→2→3→4→5 全链 |
| 阶段 4/5 出现崩溃/伪影/收敛问题 | md-simulation-workflow 的坑清单（§5 + analysis-and-pitfalls.md） |

## 4. 扩展接口（如何接入新工具/新技能）

**接入新执行技能**（如 FEP、Markov 状态模型）：
1. 复制 `templates/skill-template/` → `skills/<新技能名>/`，按模板写 SKILL.md（frontmatter 规范：name+description，description 只写触发条件）；
2. 在 `workflow.yaml` 的 `stages` 注册新阶段或挂到既有阶段的 `skill_alternatives`；
3. 在 plugin.json 的 keywords 补触发词；
4. 数据契约：声明 inputs/outputs，尽量复用既有产物格式（prmtop/nc、model.cif、FASTA）。

**接入新引擎**（如 GROMACS 作为阶段 4 备选）：
- 在 md-simulation-workflow/references/md-engine-comparison.md 注册引擎档位与迁移注意；
- 编排层无需改代码——路由按 skill_alternatives 降级。

**质量门禁（所有新技能共用约定，已写入 workflow.yaml conventions）**：
- 官方工具优先；手写脚本先与官方输出比对确认无 bug 再运行；
- 完成判定认终结标记，不信文件存在性；改算法/续跑必失效全部缓存；
- 所有参数标实证来源，未实证项标 ⚠️；每项目独立 handoff.md。

## 5. 阶段间检查点（防错传递）

- 1→2：FASTA 清洁（无 */小写混杂）；家族结论已写入 VERDICT.md。
- 2→3：置信度文件齐备；AF3 输出布局与后处理 `--layout` 参数匹配。
- 3→4：进入 MD 的结构已过质量判定（预测结构 pLDDT/四象限合格）；质子化态有依据（PROPKA 或文献）。
- 4→5：生产轨迹**收敛判定通过**（双判据）；未收敛不排能量计算（否则段间 SD 淹没排名）。
- 5→输出：报告口径统一（末 100ns 窗 + 块平均 SEM + 双口径排名稳健性声明）。

## 7. GPCR 功能性 binder 筛选级联 Pipeline v4 (⚠️ 2026-11-05 Mol-1 迁移版, 基于 v3 2026-10-18 对照实验校准版)

**2026-11-05 引擎切换 (用户定稿)**: 主引擎 AF3 → **Mol-1** (Apache-2.0 可商用; 抗原-抗体四基准全面超 AF3: FoldBench-AB 75.0 vs 48.8; 本机 4090 快 3-5×; 13 体系切换验证 r(Mol-1,AF3)=-0.21, ipTM 标度不兼容——**v3 全部 AF3 标度绝对阈值对新引擎失效, 均标待校准**); S0.5 triage OD → Mol-1 (更快); MSA 改走 Mol-1 本地 MMseqs2 server (热缓存 40s-2min/链, 详见 structure-prediction-analysis §2)。AF3 退役为保险丝 (§7.5)。OD 角色不变 (S1 正交 + S3 三元正交)。

**适用**: 设计 GPCR 激动剂/拮抗剂 binder 的全链路筛选。核心原则: **效价 (激活/抑制) 判定与亲和力判定分轨** — 亲和看双轴置信, 效价看三元 Gs 偶联, 模板回声用消融排除。详见 structure-prediction-analysis §8。

### 7.1 级联结构 (计算量从小到大, 废候选早出局)

| 阶段 | 体系 | 引擎/seeds×samples | gate |
|---|---|---|---|
| **S0.0 靶点校准面板** | 阳性/阴性对照 + 候选库背景快照 | Mol-1（见 §7.6，每靶点一次性 ~1-1.5h） | **产出本靶点阈值表**（S0.5/S1/S3 全部 ipTM 门），写入项目 handoff |
| S0 生成 | **二元** (binder+受体) | boltzgen/AnewOmni | — (三元生成归因混淆+成本 1.6×, 禁) |
| S0.5 triage | 二元 | **Mol-1 单引擎** (Ab/Ag 主场), 5s×1 (sample=1, ICC 实证伪重复) | ipTM<弃置线弃; 弃置线-复核线间触发 25s×1 复核。**两线由 S0.0 靶点阈值表给出**（v3 的 0.4/0.65 系 OD 标度仅作结构参考） |
| S1 双轴 | 二元 | **Mol-1+OD 各 100s×1** (OD 免模板 AB 正交) | 姿态 dominant + gate v2 (§5)。**聚类池下限与轴二高置信门由 S0.0 阈值表给出**（v3 的 0.40/0.65 系 AF3 标度仅作结构参考） |
| S2 sanity | 二元 | — | 能量伪影只 flag 不排序 (dG>+20 REU); binder↔Gs 冲突预检 |
| S3 三元效能 | 5 链 (+Gα/Gβ/Gγ) | **Mol-1 ≥50s×1 主读 (⚠️ 初期与 OD 20s×1 双读并行, 'AF3 唯一可读 de novo' 结论对 Mol-1 未验证)** | **gate = 联合组装占比** (pair(A-B) 与 pair(R-Gα) 门由 S0.0/对照面板给出; BC-only=伪影)。⚠️ 确认 Mol-1 summary 有无 chain_pair_iptm, 无则从 PAE 算 |
| S3.5 消融探查（可选） | 二元仅非活性模板 | 25s×1 | **单向 assay**：通过=强内在激活证据；失败不结论（α-MSH 也坍缩 0/125） |
| S4 能量+交接 | — | pyro+MMGBSA | 六道审核防线 (§6) |

**三元引擎使用细则 (2026-10-21 真 pN162 平反后定稿; ⚠️ AF3 行结论保留为历史参照, Mol-1 待重验)**: 真实/已知序列 → OD 三元完全可靠 (真 pN162 5/5 摆口袋 vs 实验 2.7Å; Nb35 5/5 摆 Gs 界面); de novo 候选主读 → ~~AF3~~ **Mol-1** (原"AF3 唯一可读"系 AF3 时代结论, Mol-1 主读能力需首批候选+实验回验; 已知 AF3 假阴性: 真激动剂 0/20, 读数=组装难易度排序非激动检测); de novo 正交复核 → OD 三元 20s×1 (必须配几何验证, 漂移名单与主读引擎互验); OD chain_pair_iptm=姿态置信≠接触 (Nb35 AB 0.813 但距受体 16.6Å) — 一切多链 pair 必须几何伴随; S3 主 gate = 主读引擎 ≥50s×1 联合组装占比 + OD 正交复核。

**seeds×samples 配置依据 (2026-10-20 ICC 实证, AF3 系架构共性, Mol-1 同构适用⚠️待抽验)**: sample 是伪重复 (与 seed 共享 featurization+模型条件, 仅重掷扩散噪声) — 三元 RG pair ICC=0.993 (组内 SD 0.018); 二元 iptm/pairAB ICC=0.77-0.89 (组内 SD 0.03)。**统计单位=seed**: sample 5→1 省 ~40-50%/seed, 同预算 seeds ×1.8-2; 等预算模拟 (p=0.4): 25s×1 CI 宽度 ≈ 5s×5 一半。历史 5×5 批不重跑, 按 seed 聚合即等价。

### 7.2 三元判读标尺 (α-MSH 对照校准实测; ⚠️ AF3 标度, **Mol-1 迁移后对照面板必须用 Mol-1 重建一次**)

- **50% 高 pair = 天然激动剂基准** (α-MSH 原生肽 SYSMEHFRWGKPV, 50 samples); 判读档: ≥50% 激动级 / 30-50% 弱激动倾向 / <20% 非激动
- corr(pair,S1)≈0.4-0.5 + 高/低 pair 样本 TM6 差 ~1Å (跨对照与候选一致) → 构象选择信号真实, pair 承载激活信息
- S1 复合分客观化: 熵权法/CRITIC + simplex 扰动扫描 (Kendall τ) + 帕累托前沿双轨; cAMP≥12 点后切 logistic

### 7.3 红线禁令 (对照实验实证)

1. **混合活性/非活性模板的二元 S1 不得作效价结论** — 受体构象跟随模板组成而非 binder (0094 实证: 4 模板 S1 0.842 → 仅 6W25 模板时 0.324, TM6 9.0Å 全闭); **消融是单向 assay** — α-MSH 天然激动肽也坍缩 (S1 0.308, 0/125), 消融失败不能证伪; 仅"超出肽参照的激活尾巴"可作加分项
2. **多链预测接触数无区分力** — 模型必须摆出所有链 ("Gs 搭上去"是输出假象); 读数用 chain_pair_iptm; 弱偶联体系的 binder-Gs 2-3Å "冲突"是链错位退化, 非真拮抗
3. **三元 S1 只记录不作 gate** (Gs+活性模板把全员压到 0.77-0.80, 基线 0.738)
4. 三元 Gs 链配 MSA (裸序列压低绝对校准; 候选间相对比较不受影响)
5. 肽对照线性化须诚实注记 (丢环化/D-残基 → setmelo/shu 线性版仅差 1 残基, 阴性弱); α-MSH 原生序列是唯一精确标尺; 真肽用 CCD 编码

**工具链**: build_ternary_inputs.py (5 链 json, 顶层 dict+dialect alphafold3) / ternary_postprocess.py / build_ctrl_inputs.py + ctrl_postprocess.py (对照与消融)。链级模板机制: templates 挂 query 链只约束该链自身构象, 链间摆放靠模型训练先验。⚠️ Mol-1 输入用 mol dialect (proteinChain/序列/MSA 路径), 三元 5 链 json 需做一次 dialect 转换 (构造器待适配)。

### 7.4 对照面板 (靶点级一次性资产, 非每批成本)

两级分离: **引擎级 QA** (跨靶点, MC4R 战役 2026-10 已定, 结论永久复用): OD 三元挤掉设计蛋白 binder、AF3 pair 有构象选择信号、多链接触数无区分力、消融是单向 assay — 新靶点不重验 (⚠️ AF3 行结论对 Mol-1 不自动继承, Mol-1 引擎级 QA 待首批重验)。**靶点级标尺** (每靶点一次性, ~1-2h): 天然激动肽定 pair 基准 (MC4R: α-MSH 50%) + 拮抗肽定地板 + 二元 TM6 基线一次; GLP-1R 例: GLP-1(7-36) + exendin(9-39)。**⚠️ 2026-11-05 Mol-1 迁移: 现有标尺全部 AF3 标度, 首批候选前必须用 Mol-1 重建靶点级标尺 (对照面板重跑一遍, 引擎级 QA 同步重验)**。**重跑触发仅四项** (日常批次零对照成本): ①引擎/checkpoint 版本 ②seeds 协议 ③MSA 策略 ④模板集/构建体变更。**同型铁律**: 肽对照不能定标蛋白 binder 构象指标; 肽线性化须注记。
6. **对照链身份层 (2026-10-20 增, 8QJ2 事故)**: 从参考结构取链必须**坐标核验** — 原始沉积坐标中测该链到各伙伴最小距 + RCSB entity 注释双确认; **禁止文件名/长度/链字母启发式**。实例: 8QJ2 链 N(138aa)=Nb35(Gs 稳定体), 真 pN162=链 D(117aa, 坐标坐口袋); 按长度取链致全部 pN162 对照污染。同族: S1 残基编号身份校验 — 一切身份假设必须核验。

### 7.5 AF3 保险丝 (2026-11-05 定, 零日常成本)

AF3 日常不再使用 (CC-BY-NC 合规考虑 + Mol-1 实测更强)。**唯一触发条件**: Mol-1 与 OD 双引擎一致判 A、但后续实验阴性 (结构-功能背离) 时, 用 AF3 对该批协议做第三方复核, 判定是引擎系统性偏差还是候选问题。触发时阈值沿用 v3 历史 AF3 标度 (本文件 §7 历史版本与 structure-prediction-analysis 归档段)。

### 7.6 S0.0 靶点校准面板（⚠️ 2026-11-05 用户定稿：每换靶点必做，与三元对照面板 (§7.4) 分立并行）

**原理**: ipTM 分布随靶点/界面类型/链数/token 规模系统性漂移 (实证: 9fm7 0.95 vs VNAR-CD3E 库 0.12-0.79 vs ALCAM 库 0.13-0.79)——**任何固定阈值只在"同靶点同分布"内有效**。S0.5/S1/S3 的全部 ipTM 门由本面板产出，v3 历史数字 (0.4/0.65/0.40) 只作分档结构参考。

**最小校准集** (Mol-1, 总计 20-40 次推理 ≈ 1-1.5h):

| 组件 | 内容 | 预算 |
|---|---|---|
| 阳性对照 | 已知结合该靶点的 binder/天然配体（**有则必须**；无则注记缺位走降级路径） | 1 体系 × 5s×1 |
| 阴性对照 | 无关骨架/已知不结合序列 | 1-2 体系 × 5s×1 |
| 背景快照 | 候选库随机抽 8-10 个 | 各 3s×1 (~30min) |

**阈值产出方法** (定锚规则, 非硬数字):
- S0.5 弃置线 ≈ 背景 ipTM 中位数的 P50-P60；复核线 ≈ P75-P85
- S1 聚类池下限 ≈ 背景 P40-P50；轴二高置信门 ≈ max(背景 P80-P90, 阳性中位 − 0.10)
- S3 pair 门 (GPCR 类): 由 §7.4 三元对照面板给出 (α-MSH 基准等)
- **分离度校验**: 阳性对照中位应高于背景中位 Δ≥0.10 且 rank 进前 20%——不达标 = 引擎对该靶点类型读数弱, 阈值表标注局限 + 候选判读降置信措辞, 不得静默放行
- **降级路径** (无阳性对照): 阈值仅用背景分位 + 库间迁移初值, 注记"未经阳性锚定", 首批实验回验后修正

**产出与归档**: 靶点阈值表 (各线数值+样本量+日期) 写入**项目 handoff**；后续同靶点批次直接引用。

**触发条件** (与 §7.4 对照面板四项一致): ①换靶点 ②换引擎/checkpoint ③seeds/samples 协议 ④MSA 策略。模板集/构建体变更同触发。

**成本注记**: Mol-1 速度使"每靶点校准"可行 (1-1.5h)；AF3 时代同等校准需 1-2 天, 此为 v3 未做全门校准的客观原因。
